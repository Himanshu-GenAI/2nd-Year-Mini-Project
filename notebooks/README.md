# Notebooks (Exploration Only)

> **Architectural Rule:** Notebooks in this directory are reserved **strictly for exploratory data analysis (EDA), rapid prototyping, and visualization experiments**. 
>
> **No production logic belongs here.**
>
> All reusable pipelines, feature transformations, models, serving endpoints, and tests must reside within the modular `src/` and `tests/` packages.

## Notebook Directory Structure
- `01_exploratory_data_analysis.ipynb`: Initial dataset exploration of NASA FIRMS active fire hotspots, spatial distribution, seasonality, and meteorological correlations.
